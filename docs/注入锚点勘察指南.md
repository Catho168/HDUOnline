# 注入锚点实站勘察指南（注入式 UI 第二阶段前置）

> 第 19 轮产出。服务方向：**「浮窗 → 注入」第二阶段**——把助手入口进一步融合进智慧课堂原生界面（播放器控制条、全局导航等）。
> 第 15 轮已完成第一阶级（播放页顶栏 chip 注入 + PlayPanel 右栏停靠）；第二阶段的候选锚点（播放器控制条 / 全局导航 / AI 模块位）在仓库内**零 DOM 证据**，必须先实站采集再定锚点，避免重蹈第 8→9 轮「纯推演被实测推翻」的覆辙。

## 一、为什么需要你采集

注入第二阶段的候选位置都在登录后的真实页面里，且部分由 KMedia SDK 动态重建（控制条）。开发侧无法登录实站，盲写选择器必然漂移。本指南的采集片段**只读 DOM、不写入、无网络请求**，对站点零影响。

## 二、采集步骤（约 5 分钟）

1. Chrome 打开智慧课堂站点并登录，进入**课程播放页**（video-detail / play-center 任一代），按 F12 打开 DevTools → Console。
2. 打开 `scripts/hdu-dom-recon.snippet.js`，全选复制，粘贴到 Console 回车执行。
3. 页面会自动下载一个 `hdu-recon-*.json`；若无下载，在 Console 执行 `copy(__hduRecon)` 后直接 Ctrl+V 发给开发侧。
4. 在**同一播放页**再执行一次片段（间隔几秒），用于对比动态重建后的结构稳定性（重点看 `controlBar.path` 是否一致）。
5. 换一个**课程列表页 / 学习中心页**再执行一次（看 `globalNav` 与 `bodyTopLevel`）。
6. 可选：切换一门课程 / 切换清晰度后再执行一次，观察控制条与顶栏的重建行为。

## 三、每个采集项服务哪个决策

| 采集项 | 服务的注入决策 |
| --- | --- |
| `candidates.globalNav` | 全局导航挂「助手」入口的锚点与样式对齐参数 |
| `candidates.controlBar` | 播放器控制条注入「助手按钮」的可行性（KMedia 重建频率需两次采样对比） |
| `candidates.playHeader` | 第 15 轮 chip 锚点的稳定性复核（两代播放页结构是否一致） |
| `candidates.rightRail` | PlayPanel 停靠的右栏选择器复核 |
| `candidates.aiCaptionWrapper` | 站点 AI 模块位桥接探测（语义最契合，当前可能为空） |
| `kmediaGlobals` | 判断能否走 SDK 事件/API 而非 DOM 注入 |
| `video` / `bodyTopLevel` | 排除干扰项、确认页面代际 |

## 四、结果回填方式

把 2–3 份 JSON（播放页 ×2 + 列表页 ×1，如有切换课程再加）发给开发侧（贴入会话或放入仓库 `tests/.local/` 均可）。开发侧将据此：
1. 产出锚点候选表（选择器、稳定性、几何、降级路径）；
2. 更新 `docs/技术实现文档` §1.3 注入契约的锚点清单；
3. 规划注入第二阶段实施轮。

## 五、安全与边界

- 片段只读：不 append、不 remove、不改样式、不发请求、不写 storage。
- 采集内容仅含 DOM 结构（标签/类名/路径/几何）与页面 URL，**不含**课程内容、个人信息、cookie。
- 若站点页面结构含敏感信息，可只保留 `candidates` 与 `kmediaGlobals` 两段后删除其余再发送。

## 六、B 站视频页勘察（第 44 轮新增）

服务方向：**B 站工具栏注入回填**（`biliToolbarProbe` 的 `BILI_TOOLBAR_PROBE_SELECTORS` 目前是盲写候选，未经验证）与后续「B 站侧浮窗 → 注入」第二阶段。

1. Chrome 打开任意 B 站视频播放页（`https://www.bilibili.com/video/BVxxxx`），F12 → Console。
2. 打开 `scripts/bili-dom-recon.snippet.js`，全选复制，粘贴到 Console 回车执行。
3. 页面会自动下载 `bili-recon-*.json`；若无下载，在 Console 执行 `copy(__hduBiliRecon)` 后直接 Ctrl+V 发给开发侧。
4. 建议再采集一次 30 秒后的同页快照（B 站 SPA 局部重建频繁，对比 `candidates.toolbar` 各候选的 path 稳定性）。
5. 回填方式同第四节：贴入会话或放入 `tests/.local/`。开发侧据此替换 `constants.ts` 的 `BILI_TOOLBAR_PROBE_SELECTORS`（探针逻辑零改动），并决定是否把更多入口（字幕/学习中心）迁入工具栏。
