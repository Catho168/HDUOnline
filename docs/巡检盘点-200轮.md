# 巡检盘点 · 200 轮里程碑（2026-11-20）

> 第 200 轮巡检的阶段性盘点：功能地图、遗留池、风险清单。详细轮次见 `docs/巡检日志.md`（第 1–200 轮全量留档）。

## 一、项目定位

杭电智慧课堂「线上学习平台」聚合入口——Chromium MV3 浏览器扩展（WXT + React）：
- 站内（智慧课堂）播放页注入：字幕/转写、AI 标注与大纲、时间点问答、板书截图、收藏知识库；
- 站外（B 站）视频页注入：字幕获取/搜索、学习助手面板（速览/问答/AI 标注/大纲/笔记）、收藏此时刻、学习中心（知识库/今日/统计）；
- 统一学习中心：课程墙、复习计划、知识库（收藏/标签/回收站/导出）、学习统计（热力图/成就/标签统计）、今日待办、每日/每周通知。

## 二、功能地图（按模块）

### 播放页（站内）
- 断点续看、字幕生成与搜索、AI 知识标注/大纲（时间轴标记）、时间点问答、板书截图、收藏入知识库、快捷键（q/n/b 等）。

### B 站学习助手
- 速览页签（时长/进度/字幕覆盖/本周小结）、字幕搜索、收藏此时刻、AI 问答/标注/大纲、时间点笔记、多 P 跟随、会话历史、学习中心三页签、今日到期角标与全部顺延、收藏夹批量导入。

### 学习中心 · 知识库
- 收藏卡片（类型筛选/文件夹/标签看板/搜索）、批量整理（移动/打标/删除）、收藏编辑、复习卡导出、笔记汇编导出。
- 标签体系：标签管理（改名/合并）、标签统计看板（排序/搜索/趋势 4-12 周/健康度/完成率/最近完成/覆盖率目标与达标祝贺）、未打标行联动、导出 CSV（趋势/健康度/未打标行/覆盖率/目标状态/统计口径/导出时间）。
- 回收站：类型筛选/搜索/排序/勾选批量（还原/还原并复习/彻底删除）/清空确认横幅化/结果反馈条/过期倒计时/空态插画。
- 筛选快照、批量整理撤销、筛选重置。

### 学习中心 · 复习计划
- 到期/逾期/模板/紧急度筛选、关键词搜索、排序、完成/顺延/改期/跳过、批量重新入计划、清单导出（分组/完成率/标签）、逾期强调。

### 学习中心 · 统计
- 热力图（周/月窗口持久化）、成就徽章（预置 + 自定义增删改/筛选/排序/时间线）、标签统计、周期周报月报、学习目标（每周小时数/目标倍率）。

### 通知与提醒
- 每日待办通知（时刻可配）：分区计数、上周回顾、昨日成就、标签健康度（点名最久 + 窗口可配 + 开关）、覆盖率提醒（开关）、行数折叠保护。
- 每周报告（周一）：站内外时长、计划完成度、成就附录。

### 设置页
- 转写模型管理、LLM 渠道配置、学习目标与统计口径（每周目标/成就倍率/覆盖率目标/健康度窗口/自定义成就）、提醒开关组、主题、日志。

## 三、质量基线（第 200 轮时点）

- 门禁：`tsc --noEmit` 0 错误；单测 **1183/1183**（96 文件）；生产构建 **31.04MB**；e2e 冒烟 **186/186**（`npm run verify:e2e` = compile → e2e:build → e2e 门禁链）。

## 五、风险清单

1. **包体积**：31.04MB 中 wasm 运行时约 28.3MB（第 47 轮已裁剪至单 JSEP 变体）；进一步裁剪需评估按需加载。
2. **e2e 时序**：SW 冷启动波动曾致个别 check 超时——已全量改条件等待 + 关键 check 加大预算；新增 check 应沿用条件等待口径。
3. ** hosts 双勾选体系**：知识库整理模式勾选（打标/移动）与回收站勾选（还原/删除）并存——已加悬停说明 + 自动清理，仍需人工验收确认不混淆。
4. **通知长度**：每日通知附加行已有折叠保护（>3 行折叠）；新附加行需并入折叠口径。
