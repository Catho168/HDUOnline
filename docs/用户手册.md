# 智慧课堂学习助手 · 用户手册

> 适用版本：v1.1.0（Chromium 110+）
> 数据边界：全部数据保存在你的浏览器本机；音频不离开设备；插件不调用站点写接口。

---

## 1. 安装

### 1.1 从源码构建

```bash
npm install
npm run build
```

打开 `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→
选择项目下的 `.output/chrome-mv3`。

### 1.2 首次打开

安装后扩展图标会出现在工具栏。打开杭电智慧课堂：

- 校内直连：`https://course.hdu.edu.cn/`
- 校外：通过 webVPN 打开智慧课堂（地址形如
  `https://https-course-hdu-edu-cn-443.webvpn.hdu.edu.cn/`）

登录后，首页/课程列表页会自动进入「学习中心」；播放页右侧会出现「本节助手」。
在 B 站（bilibili.com）视频页，插件会提供「字幕」与「学习助手」两个悬浮入口（见第 6 节）。
登录态完全复用页面本身，插件不会询问或保存你的账号密码。

## 2. 准备转写模型

转写完全在本机运行。第一次使用前需要准备模型（三选一）。

### 2.1 内置下载

1. 打开扩展「设置 → 转写与模型」。
2. 选择档位：
   - 快速（base，约 150MB）：弱机器/只能 WASM 时的首选。
   - 标准（small，约 480MB，默认）：中文课堂质量与速度平衡。
   - 高精度（large-v3-turbo，约 1.6GB）：需要强独显。
3. 点「下载」。默认从 `hf-mirror.com` 下载，支持断点续传；下载期间可以继续使用其他功能。
4. 状态显示「已就绪」即可。

### 2.2 手动导入（国内推荐，无需等待下载）

1. 打开对应模型页（需保留目录结构）：
   - 快速：`https://hf-mirror.com/onnx-community/whisper-base/tree/main`
   - 标准：`https://hf-mirror.com/onnx-community/whisper-small/tree/main`
   - 高精度：`https://hf-mirror.com/onnx-community/whisper-large-v3-turbo/tree/main`
2. 下载整个模型目录（至少包含：`onnx/encoder_model*.onnx`、
   `onnx/decoder_model_merged*.onnx`、`tokenizer.json`、`config.json`、
   `generation_config.json`、`preprocessor_config.json`）。
3. 在设置页点「选择模型目录」，选中刚下载的模型目录。
4. 文件会写入扩展本机 OPFS，状态变为「已就绪」。

### 2.3 转写范围

默认是**片段流式**：只转当前播放位置前后 10 分钟，播放推进时自动补齐。
- 优点：长视频不会一次性拉完整段音频，内存与流量可控。
- 代价：跳过的区段没有字幕；把进度拖过去就会自动补上。
- 可在「设置 → 转写与模型 → 转写范围」把半径改为 2–30 分钟，或切回「整段」。
- 关闭「浏览时自动跟进」后，只在手动点「生成字幕」时转写。

## 3. 配置 AI（可选）

转写、收藏、统计不需要 AI；知识标注、大纲、问答需要一个大模型端点。

1. 打开「设置 → AI 服务」→「添加」。
2. 选择预设（Anthropic / OpenAI / DeepSeek / Kimi / 硅基流动 / Ollama）或手填：
   - **请求格式**：Anthropic Messages、OpenAI Chat Completions、OpenAI Responses。
   - **Base URL**：例如 `https://api.deepseek.com`（不要带 `/v1/...`）。
   - **模型**：例如 `deepseek-chat`。
   - **API Key**：只保存在本机 `chrome.storage.local`，不参与浏览器账号同步。
3. 保存时浏览器会请求该域名的访问权限；拒绝则无法保存。
4. 点「测试」确认连通，再点「启用」。

本地服务（例如 Ollama `http://127.0.0.1:11434`）默认被安全策略拒绝；需要在同一页开启
「允许本地推理端点」并确认风险提示。云元数据地址始终拒绝。

## 4. 学习中心

进入站点首页 / 课程列表页后，扩展会用学习中心覆盖页面；右上角「站点原页面」可随时切回。
右下角常驻入口坞：切回站点后仍可从这里重新打开学习中心。

### 4.1 总览

- 今日 / 本周时长、连续学习天数、完看课次。
- 本周目标进度；未达标时显示还差多少。
- 待补看课次数量与快捷入口。
- 近 7 天学习柱状图（只统计有效观看）。
- 「继续学习」会带你回到最近在看的课次。
- B 站续看（第 86 轮新增）：最近在 B 站看过视频时，继续学习区会显示续看入口，
  点击新标签打开并回到上次观看位置；无站内续学时（第 87 轮起）续看会作为主入口出现。

### 4.2 我的课程

- 课程卡片展示教师、课次数、已看时长、完看度、知识点数量。
- 展开课次后，每节显示状态与完看度，点击直接在站点打开该课次。
- 课程与课次会在你浏览站点列表页时自动同步到本机（成功同步后 15 分钟内不重复）。
- 「我的课程」页的「立即同步」可随时强制从站点重新拉取；同步失败会提示原因（例如登录已过期）。
- 课程墙支持排序（第 82 轮新增）：默认（站点顺序）/ 按完看度 / 按已看时长 / 按课程名。
- 课程墙支持搜索（第 100 轮新增）：按课程名 / 教师 / 课程代码过滤。
- 课程墙支持筛选（第 83/84 轮新增）：按完看状态（已完看 / 进行中 / 未开始）、学期与教师（自动聚合）筛选。

### 4.3 课表与补看

- 本周课表按周一至周日排列；打开站点「我的课表」时会自动同步。
- 补看清单：课次结束超过设定时间且无有效观看时列入；可点「去补看」或「已到课」排除。
- 页面上的「仅供个人参考，非考勤依据」是固定说明，请勿将其作为考勤依据。

### 4.4 知识库

- 汇总收藏的时间点、AI 回答、大纲节点、截图与笔记。
- 支持按类型、文件夹、标签（第 82 轮新增，自动聚合高频标签）、关键词筛选；可导出 Markdown 复习卡片。
- 标签看板（第 123 轮新增）：标签筛选行升级为「标签看板」——行首汇总共 N 次打标，标签 chip 带频次（# 标签 · 次数），点选即切换筛选。
- 标签管理（第 124 轮新增）：「管理标签」入口可重命名 / 合并标签（收藏上的标签名同步改写，打开时自动登记未登记标签）；收藏编辑弹层的标签输入自动联想高频标签。
- 标签统计看板（第 125 轮新增）：「标签统计」入口按标签汇总 收藏 / 复习中 / 已完成 收藏数，定位还在排队复习的知识块。
- 复习中徽标（第 102 轮新增）：待完成复习的收藏卡片显示「复习中」徽标。
- 清单 CSV 导出（第 92 轮新增）：当前筛选结果一键导出为 CSV（与看板导出同列口径）。
- 批量整理（第 88 轮新增）：点「批量整理」进入多选模式，可批量移动到文件夹或批量删除（进回收站，可恢复）；支持一键全选（第 92 轮新增）。
- 批量加入复习计划与批量打标签（第 89 轮新增）：整理模式下可将所选收藏一键加入复习计划或批量添加标签。
- 批量撤销（第 90 轮新增）：批量移动 / 打标签后可「撤销批量」恢复到操作前状态。
- 任意条目可点「加入复习」进入复习计划，到期后出现在今日待办。
- 笔记汇编导出（第 107 轮新增）：「我的笔记」区一键把全部站内时间戳笔记导出为 Markdown（按锚点时间升序）；
  第 109 轮起按课程分组（组内锚点升序，未匹配课程的归「其他」组）；
  第 112 轮起纳入 B 站外部笔记（按收藏标题分组）；
  第 115 轮起可选汇编范围（全部 / 仅站内 / 仅 B 站）。
- 更多编辑（标签、备注、置顶、删除、截图、回收站）在「学习看板」中进行。

### 4.5 学习统计

- 累计/本周/今日/连续天数；近 30 天与近 12 周趋势；课程分布与课次明细。
- 本周目标进度卡（第 110 轮新增）：本周有效学习时长对比每周学习目标（设置中可调）的进度条。
- 周报目标达成史（第 111 轮新增）：学习周报的周期列表每周期显示「X.X/Yh 目标」进度徽标。
- 学习热力图（第 77 轮新增）：周报卡下方按「周列 × 7 行」展示每日学习强度
  （站内有效观看与 B 站等站外时长按自然日合并），颜色越深当天学得越多；今天描边高亮，
  悬停格子可看具体时长，点击格子可弹出当天学习明细（第 79 轮新增：站内课程 / 站外视频
  分行列出，挂机流水标「不计入」；第 80 轮起站内行可「回看」跳课次播放页、站外行可打开
  视频页），底部有累计 / 活跃天数 / 单日峰值与图例；近 13 / 26 / 52 周
  一键切换（第 78 轮新增），学习看板（Dashboard）概览同步挂载同一热力图；
  周 / 月视图切换（第 81 轮新增）：月视图按「月列 × 当月天数」展示近 12 个月；
  月数可切换（第 100 轮新增：近 6 / 12 / 24 个月）；列标签悬停显示覆盖范围（第 101 轮新增）；
  今天的格子呼吸脉冲提示（第 97 轮新增，减少动态效果时关闭）。
- 周报 / 月报导出与环比（第 80 轮新增；第 239 轮起按钮升级为「下载周报 / 下载月报」，
  文件名带数据窗口）：周报卡可一键下载 Markdown 报告（逐周期表格 + 口径附注）；
  数字卡脚注显示较上一周期的变化（+x% / -x% / 持平 / 新增）。
- 页面底部固定展示统计口径。

### 4.6 复习计划（第 83 轮新增）

- 学习中心新增「复习计划」导航：全部复习作业三分区——待完成（按到期日升序）、
  已完成（最近优先，最多 30 条）、已跳过。
- 待完成行可「去复习」（B 站收藏直达视频对应时刻）、标记「完成」或「跳过」；
  跳过仅跳过当前一轮，不影响后续轮次。
- 头部徽标显示待完成数与今日到期数；与「今日待办」卡、学习看板复习看板同源同口径。
- 学习中心导航的「复习计划」项带待完成数徽标（第 87 轮新增）。
- 类型筛选与一键完成（第 84 轮新增）：按收藏类型（自动聚合）筛选待完成作业；
  今日到期 ≥2 项时可「今日到期全部完成」。
- 来源标注与排序（第 91 轮新增）：待完成作业显示来源（站内 / B 站），支持按到期日 / 类型排序。
- 轮次标注（第 102 轮新增）：待完成行显示第 X/Y 轮。
- 紧急度筛选（第 103 轮新增）：按今日到期 / 已逾期 / 未来快捷筛选待完成作业。

- 筛选/排序持久化（第 104 轮新增）：复习计划视图的筛选与排序跨打开保留；
  存在生效筛选时提供「重置筛选」一键还原。
- 课程筛选（第 317 轮新增）：复习计划视图可按收藏所属课程筛选（「全部课程」+ 各课程
  chips，与类型/模板/紧急度/来源/关键词筛选叠加）；选择随设置持久化，选中任一课程时
  其他课程的作业从列表隐藏，导出整页的筛选说明同步带上课程。
- 周视图条（第 105 轮新增）：顶部「逾期 + 今日起 7 天」分栏概览（列头带数量），
  点选某列即按该到期日筛选待完成作业，再点取消；空列置灰。
- 周视图（第 106 轮新增）：待完成区支持「列表 / 周视图」切换——周视图按
  「逾期 + 今日起 7 天」分栏内嵌作业行，行内可直接完成/跳过；选择跨打开保留。
- 周视图窗口档（第 108 轮新增）：周视图可切「7 天 / 14 天」窗口（14 天为 7 列双行栅格）；

- 完成记录导出（第 110 轮新增）：「已完成」分区可一键导出 Markdown（按完成时间降序，含轮次/到期日/完成时间）。

## 5. 播放页：本节助手

打开播放页后，右侧面板默认展开（可在设置中关闭），顶部胶囊显示当前课程与识别状态。

**入口说明**：插件会尝试把「学习助手」入口注入到播放器控制条附近，点开是菜单
（「本节助手 / 学习中心 / 收藏此时刻 / AI 标注」）；注入成功时，右下角的悬浮入口坞会
自动隐藏，保持单一入口。若站点页面结构变化导致注入未命中，会自动回退为原来的右下角
浮层入口，功能完全一致。入口坞的「学」标右上角会显示今日到期复习数角标（第 77 轮
新增，无到期时不显示）；打开学习中心完成复习后关闭面板，角标即刷新。

### 5.1 课次识别

站点新版播放页 `#/play-center` 的 URL 不含课次 ID。扩展会按以下顺序尝试：

1. URL 参数；
2. 正在播放的媒体地址（`CloudIPC-{课次ID}-` 或 `courseId=`）；
3. 站点自身接口请求（只读观测）；
4. 站点「上次播放」记录；
5. 页面右栏被选中的课次条目时间。

推断类证据会与当前播放地址核对。全部失败时面板显示「待识别课次」，点它可从课次列表
手动选择；识别依据会显示「手动选择」。站内切换课次时，扩展会跟随播放地址重新识别。

课次识别成功后，面板头部还会出现**本课学习小条**（第 241 轮新增）：默认收起为一行
「今日已学 X 分钟 · 本课累计 Y」，点一下展开明细（本课今日已学 / 本课累计有效时长，
数字等宽排版）和本课待办提示——复习计划里有本课今天到期的作业时显示红色
「本课今日有 N 项复习到期」，点它直达复习计划视图；没有到期作业则显示玉色
「本课今日无到期复习」。今日已学只计有效观看（挂机不计），每分钟自动刷新；
课次还没识别出来时整条不会出现，不会干扰播放器。

### 5.2 生成字幕

1. 确认模型已就绪。
2. 面板底部点「生成字幕」（或在速览页点「生成字幕」）。
3. 进度条显示当前片段、速率与预计剩余时间；可随时取消。
4. 片段模式下，播放推进会自动补齐新区域；已转区域不会重复转写。
5. 字幕默认显示在视频下方，可在设置中调整字号、颜色、位置或关闭。

### 5.3 知识标注与大纲

1. 字幕就绪后，点「标注」→「生成知识标注」。生成前可在工具行选「窗口 小 / 中 / 大」
   档位，控制标注的分块粒度（小≈5 分钟 / 中≈10 分钟 / 大≈20 分钟）；只对本次生成生效，
   不改动全局设置。
2. 生成完成后：
   - 「标注」页列出知识点、摘要、时间区间与置信度；点击跳转。
   - 「大纲」页显示两级结构；播放时当前节点高亮，可开启/关闭跟随滚动。
3. 进度条上方会出现知识点色块（可在设置中关闭），点击色块跳转。
4. 低置信度知识点会弱化显示，可一键隐藏。

### 5.4 时间点问答

1. 切到「问答」页签；问题会带上当前播放位置作为锚点。
2. 回答只依据附近字幕，并给出依据时间范围；点依据可回跳。
3. 工具行的「窗口 小 / 中 / 大」档位控制本次回答参考的字幕范围
   （小=前 2 分钟/后 45 秒，中=前 3 分钟/后 1 分钟，大=前 5 分钟/后 2 分钟）；
   只对当次回答生效，不改动全局设置。
4. 字幕不足时回答会明确说明；可扩大窗口或换一个问题。
5. 可收藏回答、开启新对话、停止生成。
   第 114 轮新增：AI 回答可一键「复制」（HDU 与 B 站双端）。
6. 「导出问答」（第 81 轮新增）可把当前会话保存为 Markdown，保留提问锚点与回答依据区间；
   第 82 轮起导出本课次的**全部**问答会话。
7. 「会话历史」（第 88 轮新增）可查看/切换/删除本课次的历史问答会话；
   第 89 轮新增按首问过滤与单会话导出；第 90 轮新增「清空全部」（两步确认）；
   第 104 轮新增历史会话的消息预览（锚点时间可点击跳转）。
6. 发送给 AI 的只有字幕文本与问题，不包含音频或视频。

### 5.5 笔记

- 在「笔记」页输入内容，自动带上当前播放时间；Enter 保存。
- 可跳转、转收藏、删除。
- 导出笔记（第 106 轮新增）：一键把本课次的全部时间点笔记下载为 Markdown（按锚点时间升序）。
- 「站点笔记」折叠区只读展示站点原生笔记，不会写入站点。

### 5.6 收藏与截图

- 「收藏此刻」保存当前时间点；AI 回答、大纲节点也可收藏。
- 「截图」取当前机位当前帧，按设置加水印，保存到本机知识库。
- 站点原生收藏状态以只读方式显示，插件收藏与站点收藏相互独立。

### 5.7 搜索

在「搜索」页输入关键词，检索本节字幕；结果带时间点，点击跳转。空结果提示会按关键词长度给建议——超过 16 字时点名「关键词较长（N 字）」引导只取核心词重搜（第 314 轮起与全站搜索空态同口径）。

## 6. B 站学习助手

在 B 站视频页，播放器右下角有一枚「学习」主入口（第 44 轮起四枚悬浮入口收敛为
一枚 + 点开向上展开的菜单：「收藏」「字幕」「学习助手」「学习中心」四个子入口依次
排开，点击即进入对应功能；点击空白处或再次点主入口收起菜单）。「学习助手」面板含
「速览 / 问答 / AI 标注 / 大纲 / 笔记」五个页签；「学习中心」面板含
「知识库 / 今日 / 统计」三个页签（见 6.7）。两者行为均跟随当前分 P（`?p=`），
切换分 P 后自动跟随。官方字幕是问答与 AI 标注的前提：没有官方字幕时这两项只给
友好提示、不发起请求；「收藏此时刻」与「笔记」不依赖字幕，始终可用。

### 6.1 字幕与搜索

- 有官方字幕的视频，字幕列表自动加载；多 P 视频按当前分 P 加载。
- 列表上方搜索框可按关键词过滤本视频字幕，点击结果跳到对应时间点（多 P 带 `?p=`）。
- 字幕导出（第 105 轮新增）：「导出 TXT / 导出 SRT」一键把当前字幕下载为纯文本
  （`[mm:ss] 文本`）或 SRT 文件，文件名带 bvid 与分 P 标记。

### 6.2 收藏此时刻

- 点工具行「收藏此时刻」，把当前播放时间点存入知识库，成功后会提示保存的时间。
- 不依赖字幕；之后在复习计划里点「去复习」会直接跳回该视频的这个时间点。

### 6.3 时间点问答

- 以当前播放位置为锚点提问，回答流式输出，可随时停止。
- 「窗口 小 / 中 / 大」档位含义与杭电侧一致（见 5.4），只对当次回答生效。
- 切换分 P 后，问答会话与字幕可用性自动跟随新分 P，不会串台。
- 「导出问答」（第 81 轮新增）可把当前会话保存为 Markdown（标题带视频名与分 P）；
  第 82 轮起导出当前视频（含分 P）的**全部**问答会话。
- 「会话历史」（第 88 轮新增）可查看/删除本视频的历史问答会话（只读预览）；
  第 89 轮新增按首问过滤与单会话导出；第 90 轮新增「清空全部」（两步确认）；
  第 102 轮新增会话总数显示；第 103 轮新增预览时间点击跳转；
  第 104 轮新增「跨 P 聚合」：聚合同一视频全部分 P 的会话，分组带 P 徽标，跨 P 查看/导出/删除；
  第 105 轮起跨 P 聚合下「导出全部」合并全部分 P 的问答记录；
  第 106 轮起跨 P 预览其他分 P 会话时，锚点时间点击直达对应分 P 的时间点。

### 6.4 AI 标注与大纲

- 「AI 标注」页签可发起生成；完成后展示知识点卡片（含时间区间），点击即跳转对应片段。
- 「大纲」页签（第 44 轮新增）展示同一份 AI 生成结果的两级大纲节点，点击节点跳到
  对应片段；当前播放位置所在的节点会实时高亮。
- 播放器时间轴上方会出现知识点标记条，随播放高亮当前知识点，点击可跳转。
- 生成前同样可选「窗口 小 / 中 / 大」档位（控制标注分块粒度，见 5.3）。
- 生成中、失败均有状态提示；失败可重试，已生成的旧结果保留。

### 6.5 时间点笔记

- 「笔记」页签记录带时间戳的想法；输入框会实时提示当前播放时间。
- 点击笔记的时间戳回到该时刻；删除需两步确认。
- 不依赖字幕，无字幕视频也能用。
- 导出笔记（第 106 轮新增）：一键把当前视频（含分 P 标记）的全部时间点笔记下载为 Markdown（按锚点时间升序）。

### 6.5a 速览页签（第 44 轮新增）

- 「速览」页签展示当前视频四格指标：视频时长、播放位置（实时刷新）、字幕覆盖
  （已获取字幕的段数）、知识标注（知识点数量）。
- 下方「回到上次的位置」提供快捷跳转 chips：上次播放断点、最近的提问位置与笔记位置，

- 顶部「本周学习」小结（第 81 轮新增）：本周站内外合计时长与较上周环比，
  完整周报见学习中心「统计」页签。
- 快捷键 `q` 打开问答、`n` 打开笔记、`b` 收藏此时刻、`[` / `]` 在大纲节点间跳转
  （输入框聚焦与 B 站播放器原生按键不响应，详见 6.10）。

### 6.6 B 站学习统计

  第 104 轮起命中带秒级锚点时深链携带 `?t=`，杭电播放页打开后自动落到命中时间点。
- 面板关闭后重开，搜索词与筛选自动恢复默认。
- 「学习」主入口右上角有今日到期复习数角标（第 77 轮新增）：有今日到期复习才显示
  （超过 99 显示 99+），完成复习后自动回落。

### 6.8 收藏 AI 回答与笔记转收藏

- 问答页签中 AI 回答完成后，可点回答旁的星标「收藏」该回答（含问题与锚点时间）；
  已收藏的回答按钮置灰，重复点击会提示「该回答已收藏过」。
- 笔记页签的每条笔记可「转收藏」进知识库；转藏后的笔记在知识库以「笔记」类型展示。
- 收藏失败时按钮保持可点，可直接重试。

### 6.9 快捷键（第 44 轮新增）

- `q`：打开「学习助手」并切到问答页签；`n`：打开并切到笔记页签。
- `b`：收藏此时刻（把当前播放时间点存入知识库，语义与杭电侧一致）。
- `[` / `]`：在「大纲」节点间步进跳转（面板打开期间可用；先在标注/大纲/速览页签
  加载过大纲数据）。
- 避让规则：按住 Ctrl/Alt/Win 等修饰键、正在输入（输入框/文本域/可编辑元素聚焦）、
  以及 B 站播放器原生占用的按键（空格、方向键、F/D/M/S/C 等）时，快捷键一律让行。
- 按键与杭电侧共用同一份配置（设置中的「快捷键」），改一处两侧同步生效。

## 8. 数据与隐私

- 转写文本、收藏、笔记、统计、截图都在本机 IndexedDB；模型在 OPFS。
- 原始音频与中间 PCM 不落盘；任务中断时仅保留必要的分片缓存，完成后删除。
- 不调用站点写接口；不读取站点 Cookie/Token；不向站点上报插件数据。
- 日志最多 200 条，URL 会去掉 query（含签名），API Key / Bearer / auth_key 自动打码。
- 「记录诊断日志」开关全入口生效（第 299 轮）：关闭后，站点页 / B 站页 / 后台 / 弹窗 / 看板 / 设置页的 debug 与 info 级日志即刻停写（无需刷新页面），警告与错误日志仍保留；重新打开即恢复记录。
- 日志可导出（第 300 轮）：「本地调试日志」区点「导出」可把当前日志存为纯文本文件（内容与界面一致、同样脱敏），排障或反馈时可直接附上；副标题实时显示当前条数（上限 200）。
- 日志级别筛选（第 301 轮）：日志展开后可按「全部 / 警告 / 错误」三档筛选，级别徽标着色，排障时快速聚焦；每条日志可一键复制（第 302 轮），筛选后的条数会自动播报（无障碍）；第 305 轮起还可按「来源」（content / asr-* / sw-* 等日志模块名）叠加筛选（第 313 轮起来源清单按日志频次排序，高频模块排前）；第 306 轮起「导出」只导出当前筛选命中的条目，筛选无命中时可用「清除筛选」一键复位；第 307 轮起「复制全部」把筛选命中的日志一次性复制为文本；第 309 轮起「导出 JSON」提供结构化导出；第 311 轮起复制被拒时会引导改用「导出」保存为文件；第 312 轮起这些操作收敛为图标按钮（悬停显示名称与条数），清空最近搜索后焦点自动回到搜索框；第 316 轮起水位显示真实日志总数、日志区展开时每 3 秒自动刷新（实时尾巴）、导出文件名带筛选摘要。
- 「设置 → 数据与隐私」可分类清除；清除前建议先导出备份。

## 9. 常见问题

**Q：演示模式的数据是真的吗？**
全部为本地生成的虚构数据（人物、课程、成绩均为虚构）。它存放在独立演示库，退出即删除，真实数据不受影响。

**Q：学习中心没有出现？**
确认当前是站点首页或课程列表页；检查设置中「在列表页接管学习中心」是否开启。
若之前点过「站点原页面」，点右下角「学习中心」恢复。

**Q：播放页没有面板？**
确认是 `#/play-center`、`#/video-detail` 或 `#/play-video`。若识别失败，面板仍会显示
「待识别课次」，从课次列表手动选择即可；完全没有面板时刷新页面并查看日志。

**Q：字幕/标注按钮是灰的？**
标注需要先有字幕；字幕需要先准备模型。AI 相关功能还需要配置并启用 AI 服务。

**Q：转写很慢？**
查看当前设备：WebGPU 独显约 3–10× 实时，核显约 1–3×，WASM 单线程约 0.2–0.6×。
可改用快速档、缩小片段半径，或关闭自动跟进后手动转写需要的片段。

**Q：为什么有的区段没有字幕？**
片段流式只转你看过的附近区域。把进度拖到目标位置，等自动跟进完成后即可。

**Q：截图失败？**
若视频直链未放行 CORS，扩展会退化为仅记录时间点；面板会提示。可稍后重试或换机位。

**Q：插件会修改站点收藏/笔记/观看记录吗？**
不会。所有站点写接口都在禁止清单中；插件数据与站点数据相互独立。

**Q：B 站「学习助手」里问答/标注提示无字幕？**
问答与 AI 标注依赖视频的官方字幕；没有官方字幕时不会发起请求，只显示提示。
「收藏此时刻」与「笔记」不依赖字幕，始终可用。

**Q：B 站悬浮入口没有出现？**
确认当前在视频播放页（含分 P）。入口与面板跟随视频页渲染；若被其他页面元素遮挡，
可反馈具体页面结构。功能异常时可查看「设置 → 数据与隐私 → 日志」。

**Q：换电脑/重装浏览器后数据还在吗？**
不在。数据只在本机；请在「学习看板 → 数据管理」导出备份，再在新环境导入。

## 10. 卸载与清理

1. 先在「设置 → 数据与隐私」清除本地数据（或直接卸载扩展）。
2. 在 `chrome://extensions` 中移除扩展。
3. 卸载会删除扩展的 IndexedDB/OPFS 数据；已导出的文件不受影响。
