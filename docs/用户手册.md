# 智慧课堂学习助手 · 用户手册

> 适用版本：v1.0.0（Chromium 110+）
> 数据边界：全部数据保存在你的浏览器本机；转写默认在本机进行，可选的云端 ASR 需你显式配置；插件不调用站点写接口。

---

## 1. 安装

### 1.1 从源码构建

```bash
npm install
npm run build
```

打开 `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→
选择项目下的 `.output/chrome-mv3`。

### 1.2 首次打开

安装后扩展图标会出现在工具栏。打开杭电智慧课堂：

- 校内直连：`https://course.hdu.edu.cn/`
- 校外：通过 webVPN 打开智慧课堂（地址形如
  `https://https-course-hdu-edu-cn-443.webvpn.hdu.edu.cn/`）

登录后，首页/课程列表页会自动进入「学习中心」；播放页右侧会出现「本节助手」。
登录态完全复用页面本身，插件不会询问或保存你的账号密码。

## 2. 准备转写

转写默认完全在本机运行（本地 Whisper）。第一次使用前需要准备模型（三选一）；
如果你更想直接用云端服务，见 §2.4「云端 ASR（可选）」。

### 2.1 内置下载

1. 打开扩展「设置 → 转写与模型」。
2. 选择档位：
   - 快速（base，约 150MB）：弱机器/只能 WASM 时的首选。
   - 标准（small，约 480MB，默认）：中文课堂质量与速度平衡。
   - 高精度（large-v3-turbo，约 1.6GB）：需要强独显。
3. 点「下载」。默认从 `hf-mirror.com` 下载，支持断点续传；下载期间可以继续使用其他功能。
4. 状态显示「已就绪」即可。

### 2.2 手动导入（国内推荐，无需等待下载）

1. 打开对应模型页（需保留目录结构）：
   - 快速：`https://hf-mirror.com/onnx-community/whisper-base/tree/main`
   - 标准：`https://hf-mirror.com/onnx-community/whisper-small/tree/main`
   - 高精度：`https://hf-mirror.com/onnx-community/whisper-large-v3-turbo/tree/main`
2. 下载整个模型目录（至少包含：`onnx/encoder_model*.onnx`、
   `onnx/decoder_model_merged*.onnx`、`tokenizer.json`、`config.json`、
   `generation_config.json`、`preprocessor_config.json`）。
3. 在设置页点「选择模型目录」，选中刚下载的模型目录。
4. 文件会写入扩展本机 OPFS，状态变为「已就绪」。

### 2.3 转写范围

默认是**片段流式**：只转当前播放位置前后 10 分钟，播放推进时自动补齐。
- 优点：长视频不会一次性拉完整段音频，内存与流量可控。
- 代价：跳过的区段没有字幕；把进度拖过去就会自动补上。
- 可在「设置 → 转写与模型 → 转写范围」把半径改为 2–30 分钟，或切回「整段」。
- 关闭「浏览时自动跟进」后，只在手动点「生成字幕」时转写。

### 2.4 云端 ASR（可选）

不想下载模型、或本机性能不足时，可在「设置 → 转写与模型 → 识别引擎」切换到**云端**。
云端走 OpenAI 兼容接口（`POST {base}/v1/audio/transcriptions`），内置预设：

- **OpenAI**：`whisper-1`（按量计费）。
- **Groq**：`whisper-large-v3-turbo`（有免费档）。
- **硅基流动**：`FunAudioLLM/SenseVoiceSmall`（FunASR 系，中文强、国内直连、有免费额度；
  同接口可换 paraformer 系列模型）。
- **自定义**：任意兼容端点。

配置步骤：选预设 → 填 API Key →「保存」（会为该端点申请访问权限）→「测试连接」。
Key 只保存在本机 `chrome.storage.local`。

**请注意**：切换到云端后，转写的音频片段（60 秒/段）会上传至你配置的端点；
设置页与播放页都会显示相应提示。请确认你信任该服务商。分片缓存按引擎隔离，
切回本地后不会误用云端的旧分片（反之亦然）。

## 3. 配置 AI（可选）

转写、收藏、统计不需要 AI；知识标注、大纲、问答需要一个大模型端点。

1. 打开「设置 → AI 服务」→「添加」。
2. 选择预设（Anthropic / OpenAI / DeepSeek / Kimi / 硅基流动 / Ollama）或手填：
   - **请求格式**：Anthropic Messages、OpenAI Chat Completions、OpenAI Responses。
   - **Base URL**：例如 `https://api.deepseek.com`（不要带 `/v1/...`）。
   - **模型**：例如 `deepseek-chat`。
   - **API Key**：只保存在本机 `chrome.storage.local`，不参与浏览器账号同步。
3. 保存时浏览器会请求该域名的访问权限；拒绝则无法保存。
4. 点「测试」确认连通，再点「启用」。

本地服务（例如 Ollama `http://127.0.0.1:11434`）默认被安全策略拒绝；需要在同一页开启
「允许本地推理端点」并确认风险提示。云元数据地址始终拒绝。

## 4. 学习中心

进入站点首页 / 课程列表页后，扩展会用学习中心覆盖页面；右上角「站点原页面」可随时切回。
右下角常驻入口坞：切回站点后仍可从这里重新打开学习中心。

### 4.1 总览

- 今日 / 本周时长、连续学习天数、完看课次。
- 本周目标进度；未达标时显示还差多少。
- 待补看课次数量与快捷入口。
- 近 7 天学习柱状图（只统计有效观看）。
- 「继续学习」会带你回到最近在看的课次。

### 4.2 我的课程

- 课程卡片展示教师、课次数、已看时长、完看度、知识点数量。
- 展开课次后，每节显示状态与完看度，点击直接在站点打开该课次。
- 课程与课次会在你浏览站点列表页时自动同步到本机（成功同步后 15 分钟内不重复）。
- 「我的课程」页的「立即同步」可随时强制从站点重新拉取；同步失败会提示原因（例如登录已过期）。

### 4.3 课表与补看

- 本周课表按周一至周日排列；打开站点「我的课表」时会自动同步。
- 补看清单：课次结束超过设定时间且无有效观看时列入；可点「去补看」或「已到课」排除。
- 页面上的「仅供个人参考，非考勤依据」是固定说明，请勿将其作为考勤依据。

### 4.4 知识库

- 汇总收藏的时间点、AI 回答、大纲节点、截图与笔记。
- 支持按类型、文件夹、关键词筛选；可导出 Markdown 复习卡片。
- 更多编辑（标签、备注、置顶、删除、截图、回收站）在「学习看板」中进行。

### 4.5 学习统计

- 累计/本周/今日/连续天数；近 30 天与近 12 周趋势；课程分布与课次明细。
- 页面底部固定展示统计口径。

## 5. 播放页：本节助手

打开播放页后，右侧面板默认展开（可在设置中关闭），顶部胶囊显示当前课程与识别状态。

### 5.1 课次识别

站点新版播放页 `#/play-center` 的 URL 不含课次 ID。扩展会按以下顺序尝试：

1. URL 参数；
2. 正在播放的媒体地址（`CloudIPC-{课次ID}-` 或 `courseId=`）；
3. 站点自身接口请求（只读观测）；
4. 站点「上次播放」记录；
5. 页面右栏被选中的课次条目时间。

推断类证据会与当前播放地址核对。全部失败时面板显示「待识别课次」，点它可从课次列表
手动选择；识别依据会显示「手动选择」。站内切换课次时，扩展会跟随播放地址重新识别。

### 5.2 生成字幕

1. 确认模型已就绪。
2. 面板底部点「生成字幕」（或在速览页点「生成字幕」）。
3. 进度条显示当前片段、速率与预计剩余时间；可随时取消。
4. 片段模式下，播放推进会自动补齐新区域；已转区域不会重复转写。
5. 字幕默认显示在视频下方，可在设置中调整字号、颜色、位置或关闭。

### 5.3 知识标注与大纲

1. 字幕就绪后，点「标注」→「生成知识标注」。
2. 生成完成后：
   - 「标注」页列出知识点、摘要、时间区间与置信度；点击跳转。
   - 「大纲」页显示两级结构；播放时当前节点高亮，可开启/关闭跟随滚动。
3. 进度条上方会出现知识点色块（可在设置中关闭），点击色块跳转。
4. 低置信度知识点会弱化显示，可一键隐藏。

### 5.4 时间点问答

1. 切到「问答」页签；问题会带上当前播放位置作为锚点。
2. 回答只依据附近字幕，并给出依据时间范围；点依据可回跳。
3. 字幕不足时回答会明确说明；可扩大窗口或换一个问题。
4. 可收藏回答、开启新对话、停止生成。
5. 发送给 AI 的只有字幕文本与问题，不包含音频或视频。

### 5.5 笔记

- 在「笔记」页输入内容，自动带上当前播放时间；Enter 保存。
- 可跳转、转收藏、删除。
- 「站点笔记」折叠区只读展示站点原生笔记，不会写入站点。

### 5.6 收藏与截图

- 「收藏此刻」保存当前时间点；AI 回答、大纲节点也可收藏。
- 「截图」取当前机位当前帧，按设置加水印，保存到本机知识库。
- 站点原生收藏状态以只读方式显示，插件收藏与站点收藏相互独立。

### 5.7 搜索

在「搜索」页输入关键词，检索本节字幕；结果带时间点，点击跳转。

## 6. 学习看板（Dashboard）

从 Popup、设置页或学习中心入口打开。

- **学习概览**：完整统计、30 天趋势、课程分布、课次明细、本周目标。
- **知识库**：全部收藏与笔记；编辑标签/备注/文件夹、置顶、删除、加入复习、导出卡片。
- **复习计划**：今日待复习、完成/跳过、复习统计。
- **数据管理**：存储占用、导出（复习卡片 / 收藏 CSV / 全量 ZIP）、导入（合并或替换）、
  回收站（30 天）、清空全部数据。

## 7. 数据与隐私

- 转写文本、收藏、笔记、统计、截图都在本机 IndexedDB；模型在 OPFS。
- 原始音频与中间 PCM 不落盘；任务中断时仅保留必要的分片缓存，完成后删除。
- 默认引擎为本地 Whisper：音频不出设备，推理在本机完成。
- 唯一的例外是你显式开启的**云端 ASR**：转写时 60 秒/段音频切片会发送至你配置的
  服务商端点；API Key 只存本机，未经启用不会上传任何音频，也不存在自动回退云端。
- 不调用站点写接口；不读取站点 Cookie/Token；不向站点上报插件数据。
- 日志最多 200 条，URL 会去掉 query（含签名），API Key / Bearer / auth_key 自动打码。
- 「设置 → 数据与隐私」可分类清除；清除前建议先导出备份。

## 8. 常见问题

**Q：学习中心没有出现？**
确认当前是站点首页或课程列表页；检查设置中「在列表页接管学习中心」是否开启。
若之前点过「站点原页面」，点右下角「学习中心」恢复。

**Q：播放页没有面板？**
确认是 `#/play-center`、`#/video-detail` 或 `#/play-video`。若识别失败，面板仍会显示
「待识别课次」，从课次列表手动选择即可；完全没有面板时刷新页面并查看日志。

**Q：字幕/标注按钮是灰的？**
标注需要先有字幕；字幕需要先准备模型。AI 相关功能还需要配置并启用 AI 服务。

**Q：转写很慢？**
查看当前设备：WebGPU 独显约 3–10× 实时，核显约 1–3×，WASM 单线程约 0.2–0.6×。
可改用快速档、缩小片段半径，或关闭自动跟进后手动转写需要的片段；
也可以在「设置 → 转写与模型 → 识别引擎」切换到云端 ASR。

**Q：云端转写准吗？贵吗？**
取决于你配置的端点与模型：硅基流动 FunASR 系对中文课堂友好且有免费额度，Groq 有免费档，
OpenAI 按量计费。质量通常优于本地「快速」档。开启后 60 秒/段音频会上传至该服务商。

**Q：为什么有的区段没有字幕？**
片段流式只转你看过的附近区域。把进度拖到目标位置，等自动跟进完成后即可。

**Q：截图失败？**
若视频直链未放行 CORS，扩展会退化为仅记录时间点；面板会提示。可稍后重试或换机位。

**Q：插件会修改站点收藏/笔记/观看记录吗？**
不会。所有站点写接口都在禁止清单中；插件数据与站点数据相互独立。

**Q：换电脑/重装浏览器后数据还在吗？**
不在。数据只在本机；请在「学习看板 → 数据管理」导出备份，再在新环境导入。

## 9. 卸载与清理

1. 先在「设置 → 数据与隐私」清除本地数据（或直接卸载扩展）。
2. 在 `chrome://extensions` 中移除扩展。
3. 卸载会删除扩展的 IndexedDB/OPFS 数据；已导出的文件不受影响。
